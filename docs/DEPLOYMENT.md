## Evidence and assurance boundaries

This production lineage remains historical wallet-attested behavior, not independent authenticated provenance. Evidence URLs, scopes and SHA-256 commitments are recorded by the immutable policy/candidate. The issuer commitment proves wallet control only; organizational independence is not established. The Git tag is unsigned. GitHub Actions API metadata does not independently prove workflow authorship, test quality or software security. The web SDK hides the final redirect origin. Legacy issuer-bound policies fail closed where authenticated provenance is required. The RSA manifest verifier is deployed and live-validated on the separate v0.1.5 validation lineage documented in [FINAL_STEWARD_MORE_INFO_CLOSEOUT.md](FINAL_STEWARD_MORE_INFO_CLOSEOUT.md); this does not change the production contract or frontend configuration.

The historical `LATEST_FINAL` cross-contract write timeout is preserved in [the Studionet issue report](STUDIONET_CROSS_CONTRACT_ISSUE.md) and [GenLayer issue #60](https://github.com/genlayerlabs/genvm-manager/issues/60). It is not claimed fixed; the finalized-message architecture avoids that synchronous path. Prior baseline deployments, the original frozen policy/candidate and the separate throwaway lineage remain historical and are not production authorities. See [LIVE_RELEASE_MATRIX.md](LIVE_RELEASE_MATRIX.md) and [deployment-manifest.public.json](../deployment-manifest.public.json).
