## Trust limits

Issuer organizational independence is not established. The RSA key fingerprint does not identify a person or organization. GitHub Actions run fields in the signed manifest remain signing-key-authenticated claims rather than independent CI verification; the contract does not verify the GitHub Sigstore bundle. The pinned web fetch SDK does not expose final redirect origins, but substituted content cannot pass the frozen key signature and issuer byte commitment. Production remains on its historical registry/gate pair; the v0.1.5 RSA path is deployed only on the explicitly separate validation lineage above.
