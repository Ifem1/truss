## Trust limits

The issuer attested exact response-byte SHA-256 commitments, and validators checked GitHub-shaped metadata against the candidate. The issuer's organizational independence is not established. The Git tag is unsigned. Actions run metadata alone does not prove independent workflow authorship, test design quality or software security. The pinned web fetch SDK does not expose final redirect origins; TRUSS limits admission-critical evidence to strict canonical GitHub API endpoint shapes and role scopes, issuer-committed bytes, and registry-side provenance checks. These limits remain explicit.
